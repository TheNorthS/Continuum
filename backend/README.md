# 知恒 · Continuum Backend

知识与记忆双驱动的长程多模态智能体平台。

Knowledge- and Memory-Driven Platform for Long-Horizon Multimodal Agents

从本目录执行 `uv sync --extra dev`，再执行 `uv run python -m app.cli init`。
开发服务：`uv run uvicorn app.main:app --reload --host 127.0.0.1 --port 8000`。
完整安装、模型配置、迁移和部署说明见 [项目 README](../README.md)。
